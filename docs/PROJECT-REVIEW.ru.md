# Ревью Pi Control

Проверена ветка релиза 1.0.2. В ревью использованы исходники, локальные проверки и диагностика Raspberry Pi. Реальный Supabase и полное восстановление рабочего USB-бэкапа требуют отдельной проверки.

| Приоритет | Наблюдение | Следующая доработка |
| --- | --- | --- |
| P0 | Пакет обновления заменяет только часть интерфейса. Python, системные службы и часть фронтенда пока ставятся отдельно. | Сделать проверяемый серверный пакет с перечнем файлов, предварительной проверкой, миграциями, проверкой доступности и откатом. Хранить состояние отдельно от кода. |
| P0 | Веб-процесс управляет системными службами и имеет доступ к данным с широкими правами. | Разделить веб-процесс и привилегированный исполнитель. Ограничить действия исполнителя явным набором команд и журналировать изменения. |
| P1 | USB-архив проверяется по размерам и SHA-256. Эта проверка не подтверждает восстановление данных и доступность ключа age. | Добавить мастер восстановления с выбором приложений, проверкой ключа и восстановлением в изолированные цели. Регулярно проверять восстановление PostgreSQL, домашнего каталога и одного приложения. |
| P1 | Файловые операции используют пути и зависят от расстановки точек монтирования. | Закреплять файловые дескрипторы на время операций, дополнить проверку вложенных маунтов и отказа питания, добавить тесты переподключения и отмены загрузки. |
| P1 | PostgreSQL ↔ Supabase реализован снимками. Задания облака хранят состояние в памяти процесса. | Перенести облачные задания в устойчивую очередь, добавить историю, сроки хранения и проверку восстановления снимка. Решение о репликации принимать отдельно для выбранных баз. |
| P2 | Интерфейс сочетает старые и новые компоненты, покрытие переводом и проверками браузера неполное. | Выделить общие компоненты ошибок, прогресса, уведомлений и кнопок. Добавить e2e-проверки входа, двух панелей, USB и восстановления. |

Предлагаемый порядок работ: серверное обновление и откат → восстановление из резервной копии → изоляция привилегий и файловых операций → улучшение облачных заданий и браузерные тесты.
