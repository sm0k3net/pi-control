# Экспериментальная установка лёгкого узла

[English](NODE-INSTALL.md) · [Статус основной установки](INSTALLATION.ru.md)

Установщик разворачивает **только лёгкую панель удалённого узла**. Он не устанавливает основную панель Pi Control, Docker Compose-стек, Tailscale, Cloudflare Tunnel, Agent Zero и другие приложения. Установщик экспериментальный: автоматические тесты используют имитации системных команд, сквозная установка на новом устройстве пока не проверена. Перед запуском изучите код. Служба узла работает от root и может управлять контейнерами и читать файлы в `/home`; открывайте доступ только в доверенной сети.

## Требования

Debian/Raspberry Pi OS с работающим systemd, Python 3 и `apt-get`, не менее 450 МБ ОЗУ и 2 ГиБ свободного места, права sudo/root, свободный порт 8484 и интернет для установки недостающих Docker или OpenSSL. Для клонирования приватного GitHub-репозитория нужен доступ к нему. Сеть и брандмауэр установщик не меняет. Это предварительные проверки, а не проверенная таблица совместимости моделей.

## Установка

```sh
git clone https://github.com/sm0k3net/pi-control.git
cd pi-control
python3 scripts/install-node.py --check
sudo python3 scripts/install-node.py
```

`--check` только читает состояние системы; окружение под `sudo` может отличаться. Установщик при необходимости поставит системные пакеты `docker.io` и/или `openssl`, создаст `/opt/pi-node` и systemd-службу, сгенерирует отдельный пароль и самоподписанный сертификат и включит службу. Существующие данные Docker не удаляются намеренно. Если каталог или служба узла уже существуют, установщик остановится: обновление и откат ещё не реализованы.

После установки получите пароль **по доверенному каналу** из доступного только root файла `/opt/pi-node/initial-password.txt`, сохраните его безопасно и удалите файл после сохранения. Учётные данные панели узла, SSH и KDBX должны быть отдельными. Хеш пароля хранится с солью; смена пароля через интерфейс узла пока не реализована.

Проверьте отпечаток сертификата по доверенному каналу:

```sh
sudo openssl x509 -in /opt/pi-node/cert.pem -noout -fingerprint -sha256
sudo systemctl status pi-control-node --no-pager
sudo journalctl -u pi-control-node -n 50 --no-pager
```

Откройте `https://<локальный-или-tailscale-ip-узла>:8484/` в доверенной сети и проверьте подключение. Узел слушает обнаруженные приватные IPv4 и Tailscale-адреса; доступ зависит от сети и брандмауэра. Сертификат самоподписанный, его отпечаток следует сверять через доверенный канал. Активная служба сама по себе не подтверждает доступ с другого устройства. Добавьте узел в основную панель с проверенным отпечатком сертификата и паролем, если установленная версия контроллера поддерживает этот сценарий.

## Если установка прервалась

Установщик не удаляет автоматически частично созданные файлы и установленные пакеты. До повторной попытки проверьте состояние службы, журнал, `/opt/pi-node` и файл unit. Перезапись частичной установки запрещена; необходимые данные сохраняйте. Механизмы восстановления и обновления предстоит реализовать и проверить.
