## English

- Give an authorized MCP gateway a node-specific diagnostic credential. A lightweight node accepts it only for read-only health, links, known neighbors and Bluetooth records. A Pi panel password is unnecessary for this connection.

## Русский

- Для MCP можно выдать отдельный диагностический токен узла. Он работает только для чтения состояния, сетевых параметров, известных соседей и Bluetooth. Пароль лёгкой панели остаётся отдельным.
