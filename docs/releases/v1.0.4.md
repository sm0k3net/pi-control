## English

- Waits for noVNC to respond on the Pi's Tailscale address before opening the browser tab.
- Starts the Windows RDP client in a terminal within the noVNC desktop so authentication and certificate prompts are visible.

## Русский

- Панель дожидается готовности noVNC по Tailscale и только затем открывает вкладку.
- При подключении к Windows запросы пароля и подтверждения сертификата видны в терминале внутри noVNC.
