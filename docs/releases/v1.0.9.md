Mac Screen Sharing opens directly inside the authenticated Pi Control origin via a short-lived WebSocket ticket and noVNC, with Apple Remote Desktop account prompts. Install the pinned noVNC browser assets with scripts/install-novnc-client.py. Knowledge adds nested content search, breadcrumbs, Markdown preview and draft status. Terminal provides separate tabs, adaptive polling and mobile control keys.

«Общий экран Mac» открывается прямо в Pi Control через HTTPS и noVNC с запросом учётной записи macOS. База знаний получила поиск по содержимому, путь к папке, Markdown-просмотр и статус правок. Терминал поддерживает отдельные вкладки и управляющие кнопки.
