## English

- Managed dashboard update with a single release check, GitHub SHA-256 validation, post-restart health checks and rollback of the managed server files and active UI version.
- Pi Nodes offers fixed read-only templates for host health, interfaces and routes, known LAN neighbors and local listeners, known Bluetooth devices, and attached USB storage. Auto selection requires a scoped stored node secret.
- Files can browse compatible USB devices attached to an enrolled lightweight node and download files up to 8 MiB. USB browsing mounts supported filesystems read-only.
- System can save Mac VNC and Windows RDP targets and launch client applications in the Pi noVNC desktop over Tailscale. The destination credentials are entered in the viewer.

## Русский

- Обновление управляемых файлов сервера и интерфейса одной операцией. SHA-256 проверяется по GitHub, после перезапуска выполняется проверка панели. При сбое восстанавливаются предыдущие версии.
- «Узлы Pi» запускают готовые шаблоны диагностики на выбранном узле или автоматически выбирают зарегистрированный узел с сервисным секретом.
- «Файлы» открывают USB на лёгком узле для чтения. Поддерживаются просмотр папок и скачивание файлов размером до 8 МиБ.
- «Система» сохраняет рабочие столы Mac (VNC) и Windows (RDP) и открывает их через noVNC на Raspberry Pi. Pi подключается к устройству через Tailscale.
