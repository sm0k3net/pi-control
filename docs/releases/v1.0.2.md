## Что нового

- USB монтируется отдельной службой. NTFS остаётся доступной между циклами обнаружения, а повторное подключение обрабатывается по идентификатору носителя.
- В «Файлах» появились быстрый выбор USB, повторная проверка, статусы подключения и навигация по пути. При переключении носителей устаревшие ответы больше не меняют активную панель.
- В исходниках доступны зашифрованные USB-копии, уведомления и снимки PostgreSQL в Supabase Storage.
- Восстановление PostgreSQL выполняется в новую локальную БД. Проверено восстановление тестового архива с клиента 17 на сервере 16.

## Установка

Встроенный updater устанавливает только пакет интерфейса. Для USB-монитора и файловых изменений нужны серверные файлы и службы из исходников этого релиза. На действующем устройстве обновляйте код отдельно от локальных конфигураций, секретов и данных. Установка на новые устройства описана в документации.
