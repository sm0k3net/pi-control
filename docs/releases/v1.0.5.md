## English

- Separate Apple Screen Sharing, standard VNC and Windows RDP profiles. Saved profiles are editable. Windows can prompt for an account name when a profile has no username.
- Lightweight node sign-in redesign, Wi-Fi and Bluetooth discovery, and manual IPv4 inventory of common services on a directly connected private LAN.
- Browser uploads and downloads in the node's transfer folder. Copy files between enrolled nodes from the main panel with progress, without staging the file on the controller.
- Scoped diagnostic MCP gateway for selected enrolled nodes. Includes stdio and optional HTTPS on Tailscale.

## Русский

- Отдельные профили Apple Screen Sharing, обычного VNC и Windows RDP. Карточки можно редактировать. Windows запрашивает имя пользователя, если оно не сохранено.
- Новый вход лёгкой панели, обнаружение Wi-Fi и Bluetooth, ручная инвентаризация распространённых TCP-сервисов в напрямую подключённой локальной подсети.
- Загрузка и скачивание в папке обмена, потоковое копирование между узлами через основную панель с отображением прогресса.
- MCP для диагностики явно разрешённых узлов через stdio или HTTPS в Tailscale.
